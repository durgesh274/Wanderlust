#  Wanderlust

**Wanderlust** is a full-stack property listing web application inspired by Airbnb, where users can explore travel stays, discover properties, and manage their own listings. Built using Node.js, Express.js, MongoDB, EJS, and Bootstrap, the application provides a responsive and user-friendly experience.

## ✨ Features

- 🏡 **Property Listings** — Browse available properties and view their details.
- 🔐 **User Authentication** — Register and log in to access user-specific functionality.
- 📝 **Listing Management** — Create, edit, and delete property listings.
- 📱 **Responsive Design** — Access the website across desktop and mobile devices.
- 🗄️ **Database Integration** — Store and manage property and user data using MongoDB.
- 🎨 **Dynamic Templates** — Render dynamic web pages using EJS.
